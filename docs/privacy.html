Privacy policy

Last updated: 18 October 2026

The SutraVerse Uploader ("the app") is used only by the owner of the SutraVerse YouTube channel to upload SutraVerse's own videos to that channel. It is not offered to the public.

What data the app uses

The app uses Google OAuth with the YouTube Data API scope youtube.upload to upload videos, titles, descriptions and tags to the channel owner's own YouTube channel. It does not read, collect or store any other Google user data, and it does not access any data about viewers.

Storage and sharing

The OAuth credentials are stored privately as encrypted environment settings available only to the channel owner's automation. No data is sold, shared with third parties, or used for advertising.

YouTube

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy. You can revoke the app's access at any time at Google security settings.
