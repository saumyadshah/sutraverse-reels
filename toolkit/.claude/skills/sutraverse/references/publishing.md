# Publishing package (English by default)

Write `renders/publish.md` from `templates/publish_package.md` after QA passes.

- **Titles (3 per platform):** curiosity + accuracy. Name the source when it adds trust ("…| Bhagavad Gita 2.62"). No claims the video doesn't support, no ALL CAPS, no fake urgency. Shorts ≤ 60 chars; YouTube long ≤ 70 chars with the key phrase early.
- **Description:** 2–3 lines on the modern problem and the teaching, then "Sources:" with exact references and translations used, then chapter markers for long-form (from `timing.json` scene starts), then credits (voice/licence notes, music provenance, fonts if required).
- **Instagram caption format (house rule):**
  1. Hook line, then one or two lines of insight, then the CTA (save / share / follow).
  2. A blank line, then a **keyword line**: relevant search keywords separated by commas, as many as are genuinely relevant (aim for 25–40). Mix the scripture, verse reference, characters, the theme, the modern problem, English and Hinglish search phrases people type ("bhagavad gita in hindi", "krishna motivation", "upanishad quotes", "ravana story"), and the festival if there is one. Keep the whole caption under 2,200 characters. Use no keyword that isn't true to the post.
  3. A blank line, then **exactly 5 hashtags**: 1 brand (#SutraVerse), 2 broad niche tags (e.g. #HinduScriptures #AncientWisdom #BhagavadGita #Upanishads #Vedas), and 2 specific topic tags. Never more, never fewer.
- **Pinned first comment:** one question that invites comments.
- **YouTube:** the same keyword line in the description, plus 3 hashtags.
- **Thumbnail concept:** one focal image from the video's own world, 2–4 English words, high contrast, the gold/midnight palette; describe composition + text + which frame/time to pull from.
- **Pinned comment idea:** a reflective question.

Never misrepresent the scripture in metadata; uncertainty noted in the video must also be reflected in the description.
