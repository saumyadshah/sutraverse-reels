# SutraVerse brand kit v4: "Mithila Night"

Real-life stories, ancient answers. Ink-dark cinematic scenes, natural Mithila pigments, Indian-designed type.
Rules: `toolkit/CONTENT_STANDARDS.md` §6–8, §15–16. Captions: `toolkit/CAPTION_STRATEGY.md` (v4).

- `brand.css`: colour and type tokens, chip, headline, subtitle, ancient-voice and wordmark classes. Link it from any HyperFrames composition.
- `fonts/`: Anek Latin and Anek Devanagari (Ek Type), Fraunces (Undercase Type), Tiro Devanagari Sanskrit (Tiro Typeworks). All SIL OFL 1.1; the licences are included.
- `motifs.py`: original Mithila-inspired SVG building blocks (double-outline hatched frame, fish, sun, archer, modern character) to start a scene from.
- `cover.py`: the cover/thumbnail generator (series chip, headline, ancient line, wordmark, optional Mithila inset). It writes a grid-size preview too.
- `blender/portal_sting.py`: the Paper Portal world-change transition (Cycles on CPU). `blender/diorama_plate.py`: a lit paper-diorama still plate with 3D type.
- `assets/portal/`: the pre-rendered portal frames (720x1280, 30 fps). Scale them to 1080x1920 with lanczos and crossfade at the bright core.
- `samples/`: the brand board, two covers and four style frames (modern scene, thread transition, verse card, explainer).
