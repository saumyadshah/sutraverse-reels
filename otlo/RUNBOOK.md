# Otlo daily Reel runbook

Otlo (ઓટલો, Instagram **@otlo.gujarat**) is Saumya's faceless Gujarati culture, food and cinema brand.
Every post is a Reel with a Gujarati voice-over, English subtitles and bilingual on-screen text, in the
"Kankotri Press" style. A scheduled run follows this file **exactly**, works unattended, asks nothing, and
posts **at most one Reel a day**.

## Hard rules (never break)

1. **One Reel per day, only today's row.** Today = the date in Asia/Kolkata. If today's row is missing, or its
   Status is `Posted` or `Skipped`, or `otlo/logs/<today>.md` already says POSTED, stop and log why.
2. **Facts.** Every factual claim (dates, tithis, history, numbers, release dates, box office) needs two
   independent reliable sources found today with WebSearch/WebFetch (start from column G). Drop any claim you
   cannot confirm. If the topic's core cannot be confirmed, mark the row `Skipped` with the reason and post nothing.
   Religious practice is described as belief/tradition ("it is believed", "many families"), never as fact or advice.
   Puja times: say they vary by city and point to the local panchang.
3. **Cinema.** No film clips, stills, posters, trailers, logos or actors' faces, ever. *Loko Shu Kahe Chhe?*
   reports what named critics and audiences said (attributed, short quotes only in the caption with the outlet
   name); Otlo gives **no verdict of its own**. Box office numbers only with a named source, labelled "reported"/
   "estimated". *Box Office no Hisaab* follows the same rule.
4. **People and communities.** No real private individuals. No caste, communal, political or religious
   ridicule; no stereotypes of any city or community beyond gentle, affectionate food rivalry.
   *Family Group Chat* is original comedy with invented characters (Ba, Mummy, Pappa, Fai, the NRI cousin).
5. **Copyright.** No song lyrics, film dialogue, or third-party images/audio. All art is our own inline SVG; the
   music is generated by the toolkit.
6. **Images must match the subject.** Khaman must look like khaman, a kite like a kite. Draw it carefully in SVG.
7. **No sponsored content, no paid links, no replies/DMs, no deleting posts, no edits to other accounts.**
8. **When in doubt, skip.** A skipped day is fine; a wrong or offensive post is not. Always log the reason.

## Steps

### 1. Set up
```
cd $HOME && (test -d sutraverse-reels/.git && git -C sutraverse-reels pull -q || git clone -q https://github.com/saumyadshah/sutraverse-reels)
```
(If the clone or push is refused, use add_repo with owner `saumyadshah`, repo `sutraverse-reels`, access `push`.)
Work dir: `otlo/work/<YYYY-MM-DD>-<short-slug>/`.

### 2. Read the calendar
Read `A1:H80`. Find today's row and the next row (for the end card's "Next:" line). Note Time (default 19:30).
Format "Carousel" or "Reel + carousel" → still make a Reel (Reels-first).

### 3. Research
Follow hard rule 2. Keep a list of sources (title + URL). For a reception/box-office topic, gather published
reviews, ticketing-platform audience score and named trade estimates.

### 4. Script → `script.json`
```json
{"voice":"Kore","direction":"","lines":[
  {"id":"s1","gu":"<hook, ≤ 90 chars>","en":["subtitle chunk","subtitle chunk"]},
  ... 5–7 lines in total; the last is always:
  {"id":"sN","gu":"ગુજરાતની વાતો, ઓટલા પર. ઓટલોને ફોલો કરો.","en":["Stories of Gujarat, on the otlo.","Follow Otlo."]}
]}
```
- Natural, warm, spoken Gujarati (as a friend on the otlo would say it), 60–160 characters per line;
  total spoken length about 35–55 s. Numbers: write them as Gujarati words when they would be said aloud.
- Line 1 is the hook (a surprising fact, a question, or a playful line). One line near the end invites a comment.
- `en`: faithful plain-English subtitle chunks of ≤ 55 characters each, covering the whole line.

### 5. Scenes → `reel.html`
Copy `otlo/toolkit/templates/reel-skeleton.html`. One `.scene` per script line, same order. Keep the END CARD
block and set its "Next:" text. Use the brand classes (`.chip .gu .en .kick .body .box .art`) and colours
(ivory #F3E9D6, indigo #1B2A4A, red #A8322A, haldi #E3A21A, rani #C2185B sparingly, leaf #3C7A3A for art only).
Each scene: Gujarati headline + English headline (uppercase condensed) + optional short body + one SVG
illustration of the real subject. Keep the bottom 260 px free (subtitles). Use `otlo/toolkit/examples/` as
the quality bar. `data-s`/`data-e` are the original timings (about 5 s a scene); they stretch to the voice.

### 6. Build (GitHub Actions does voice + render)
```
echo "otlo/work/<dir>" > otlo/toolkit/queue.txt
git add -A otlo && git commit -m "Otlo: <date> <slug> script" && git pull --rebase && git push
```
Then poll every 30 s (`git pull`) for up to 25 min until `otlo/work/<dir>/build.log` contains `BUILD OK` or
`BUILD FAILED` / `NO_KEY` / `VOICE FAILED`.

### 7. Review (must pass all)
- Read `contact.jpg` (one frame per scene) with the Read tool: text fits, nothing overlaps, Gujarati renders,
  art matches the subject, subtitles sit under the art.
- `qa.json`: `ok` true, no `warnings`, duration 15–90 s, lufs about -14.
- A warning about chars/sec means the voice may have read something extra or cut off: re-record by deleting
  `vo/*.wav`, fix the line, re-queue. A layout problem: fix `reel.html`, re-queue (vo is reused).
- At most 2 rebuilds. Still failing → row `Skipped`, log, stop.

### 8. Caption → `caption.txt` (≤ 2,200 chars)
Gujarati line, then the same in English; a short "what you'll learn" pair; a bilingual comment prompt;
a "Sources:" line naming the outlets (no long quotes); `Illustration and voice: Otlo.`;
`Follow @otlo.gujarat for what Gujarat is watching, eating and celebrating.` + `ગુજરાતની વાતો, ઓટલા પર.`;
4–6 hashtags (topic in English and Gujarati, `#GujaratiCulture` or `#GujaratiCinema` or `#GujaratiFood`, `#Otlo`).

### 9. Post
- Before posting, check `vidiq_social_post_list` / the log so nothing was already posted today.
- Wait until the row's time (IST) if it is still ahead; if it has passed, post now.
- `vidiq_video_upload` with `url=https://raw.githubusercontent.com/saumyadshah/sutraverse-reels/main/otlo/work/<dir>/reel.mp4`
- `vidiq_instagram_publish_reel` with platformAccountId `29167885212872260`, that videoUrl and the caption; no
  trial, no AI label unless Saumya asks. Continue with containerId every ~10 s until `PUBLISHED`. Stop on errors
  (do not retry a failed publish); if access expired, log "RECONNECT NEEDED".

### 10. Record
- Calendar: Status → `Posted` (or `Skipped`), and append the permalink (or the reason) to column G.
- Write `otlo/logs/<YYYY-MM-DD>.md`: row, POSTED/SKIPPED, permalink, sources, QA numbers, anything odd.
- Empty `otlo/toolkit/queue.txt`, commit and push everything (`git pull --rebase` first).
- Finish with one line: what was posted (with link) or why not.
