# SutraVerse toolkit

Copy into an OpenMontage checkout (github.com/calesthio/OpenMontage) at the repo root:

    cp -r toolkit/. <OpenMontage>/

Contains the SutraVerse skill (.claude/skills/sutraverse), patched tools/audio providers, styles/sutraverse.yaml and the vendored Ootto content skills (MIT). No secrets: the Gemini key comes from the GEMINI_API_KEY environment variable.
