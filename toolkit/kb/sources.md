# Sources and how to cite them
- **Chanakya Niti** (Chanakya Niti Darpan): verse numbering differs by edition; cite "Chanakya Niti <ch>.<v> (<edition>)" and say "attributed to Chanakya". Reference editions: the widely used English rendering in public domain collections; check the Sanskrit on two sites before showing Devanagari.
- **Arthashastra**: cite Book.Chapter (e.g. 1.11); translations: R. P. Kangle (critical edition), L. N. Rangarajan (Penguin). Authorship/dating is debated: "the Arthashastra, traditionally attributed to Kautilya".
- **Panchatantra / Hitopadesha**: cite the book (tantra) and story; versions differ: "in one telling…".
- **Bhagavad Gita / epics / Puranas**: CONTENT_STANDARDS §4 (two editions; BORI critical edition for the Mahabharata where numbering differs).
- **Psychology**: name the study (authors, year, journal) or the concept's originator; prefer replicated findings; say "studies suggest" when evidence is mixed.
- **History**: reputable academic or museum sources; "c." for uncertain dates; Greek sources for Chandragupta (Megasthenes via later authors; Plutarch, Justin) are labelled as such.
- **Legends and later tradition** (e.g. Chanakya's shikha vow, the Mudrarakshasa play): label "Tradition holds".
